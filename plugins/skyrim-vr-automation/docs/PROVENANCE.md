# Provenance

The initial `v0.1.0` baseline was preserved on 2026-08-20 from operational
tooling developed during Skyrim VR integration and rendering tests. The
null-HMD profile originated in a completed CSX integration-test handoff.

The original working directory was not a Git repository. This repository is
therefore the first durable version-control boundary for the toolset. Historical
machine paths and local configuration were intentionally omitted; the ignored
local configuration is not part of the public baseline.
